How updates work

  • Bike Ops deploys without interrupting work mid-job or mid-chat.
  • When a new version is ready, staff see an Update available notice in the sidebar above Sign out.
  • The new version applies only when someone clicks Update now. A normal refresh keeps the current version until then.
  • Open What's new anytime to read the notes for that release.
